# Host — Luồng chủ cơ sở

- `pages/` — Dashboard, quản lý không gian, đơn đặt, báo cáo, thanh toán, hồ sơ.
- `partials/` — Thành phần EJS riêng (ví dụ wizard thêm cơ sở).
- `public/js/` — Script client (`host-spaces.js`), phục vụ qua static `Host/public`.
- Routes host: `/host/*` trong `server.js`.
